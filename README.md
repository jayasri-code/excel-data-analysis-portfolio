#  Sales & Profit Dashboard

# Project Overview

An interactive Excel dashboard created to analyze sales and profit performance across products, categories, regions, and months.

# Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Data Cleaning
- Data Analysis

# Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold
- Monthly Sales Trend
- Sales by Region
- Sales by Category
- Top Products by Sales
- Interactive Region and Category Filters

# Key Insights

- Total Sales: ₹852,038.45
- Total Profit: ₹161,430.78
- Total Orders: 500
- Electronics generated the highest sales among the categories.
- Laptop was the highest-selling product by sales.
